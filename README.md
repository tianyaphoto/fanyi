# 翻译神器（Fanyi）

**中文** · [English](README.en.md)

一个轻量的 macOS 菜单栏翻译工具：看文档时划词就能翻译，截图也能翻译，还能把不熟悉的词收进生词本。翻译由大模型完成，可以接 Claude API、AWS Bedrock、OpenAI API、DeepSeek、通义千问和其他 OpenAI 兼容服务，也可以直接调用本机的 Claude Code（`claude -p`）。

## 功能

- **划词翻译**：在任意应用里选中文字，鼠标旁出现翻译小图标，点击即可翻译；也可以选中后按快捷键（默认 `⌥D`）。
- **截图翻译**：按 `⌥S` 框选屏幕区域，本地 OCR（Apple Vision）识别文字后翻译。适合图片、PDF 扫描件、视频字幕。
- **看图翻译（可选）**：在设置里打开后，截图本身会直接发给模型，表格、公式、手写体的效果更好，但更慢、更费额度。
- **输入翻译**：按 `⌥A` 弹出输入框，打字后按回车翻译。
- **单词秒出**：查英文单词时，先从 macOS 系统词典（如牛津英汉）即时显示释义，AI 释义随后流式补充。
- **智能翻译**：单词给出音标、词性释义和例句；句子和段落直接给出通顺译文；选中中文时自动翻成英文。
- **多语言**：默认中英互译。设置里可以换成任意两种语言（例如越南语 ⇄ 英语、英语 ⇄ 韩语、日语 ⇄ 中文，共 16 种）：一种译成另一种，其它语言都译成主要语言。浮窗上的「→ 语言」可以临时指定这次译成哪种语言。截图识别也会按设置的语言识别。一键改写不受影响，总是输出英文。
- **结合语境**：划词时会同时读取这个词所在的原句，AI 会先说明它在这句话里的具体含义。
- **生词本**：一键收藏单词或句子，并自动保存当时的原句（生词高亮）和来源文档，复习时能回到当初的语境；没读取到原句时可以手动补充。支持搜索、标记已掌握、删除。
- **查词历史**：自动记录查过的内容；同一个词查到第 2 次起会提示「第 N 次查询」，方便发现该收藏的生词。
- **自定义快捷键**：在设置里录制自己的组合键，被其他应用占用时会提示。
- **浮窗操作**：朗读原文、复制译文、固定浮窗，按 Esc 关闭。长文本自动用大浮窗，原文可折叠，译完后可以逐段「对照」；浮窗会避开选中的文字，不挡住原文。
- **翻译场景**：内置通用、文档、技术、学术、邮件与聊天、合同与条款六个场景，每个场景有自己的翻译要求（例如文档保留标题和列表结构、术语前后一致；技术内容保留代码和命令）。按当前 App、窗口标题和网址自动选择，浮窗里可以临时切换，或记住「以后这个网站都用这个场景」。要求和识别关键词都能改，也能新建自己的场景。
- **资料库与术语表**：把项目文档、产品说明、以前的译文（文本、Markdown、PDF、Word、RTF、HTML）加进资料库，翻译时在本机检索出最相关的几段作为参考；术语表里的词必须按给定译法翻译。浮窗会显示这次参考了哪些内容。
- **一键改写（输入框）**：在聊天框或文档里按 `⌃⌥⌘T`，自动全选、复制，中文和中英混合译成英文，英文纠正拼写语法、改成自然简洁的工作表达，然后用 `⌘V` 替换原文；不会按回车发送。也可以先复制文字，按 `⌃⇧⌘C`，改写完自动粘贴到当前有焦点的输入框。默认英式拼写，可改美式；可以分别给“译成英文”和“英文润色”加自定义要求。详见下面「一键改写」。
- **剪贴板历史**：按 `⌃⌥⌘V` 弹出最近 10 条复制过的文字，可以搜索；点一条（或回车）就把它放回剪贴板第一条，并自动粘贴到当前输入框。只保存在内存里，退出即清空；密码管理器标记为隐藏的内容不记录；设置里可以关闭。
- **Google 文档**：Google 文档、幻灯片、表格的正文画在画布上，读不到辅助功能文字，会自动改用拷贝取词。

## 一键改写

- **两个快捷键**（都可以在设置里改）：`⌃⌥⌘T` 改写当前输入框（全选 → 复制 → 改写 → 替换）；`⌃⇧⌘C` 改写剪贴板里的文字，改完自动粘贴到当时有焦点的输入框（等待时换了窗口或输入框，就贴到新的位置），结果同时留在剪贴板里。按完快捷键请松手，等结果自动替换。
- **安全**（改写当前输入框）：先记下当时的应用、窗口和输入框；粘贴前确认目标没变、等待期间没有打字或点击、剪贴板没被换掉，否则不自动粘贴，结果留在剪贴板里由你手动粘贴。能读取输入框文字的应用（大多数原生应用和打开了辅助功能的 Electron 应用），粘贴后会回读整个输入框确认替换正确；读不到时会提示“无法确认”，避免重复粘贴。成功时不弹窗，出问题时在屏幕上方显示一条不抢焦点的短提示。
- **不改坏内容**：链接、行内代码、代码块先换成占位符，改写后原样还原，占位符被模型改坏就不写入；空输入、复制失败、网络失败、超过 10,000 字、结果不像改写（不是英文、问句被回答）时，原文不动。同时只运行一个任务，30 秒超时，可以从菜单取消。
- **菜单**：「复制上次改写结果」「复制上次改写原文」（原文和结果只在内存里，退出即清除）、「诊断日志…」（最近 250 条步骤记录：快捷键是否收到、全选和复制是否完成、HTTP 状态和耗时、为什么没自动粘贴；不记录原文、结果和密钥）。
- **设置 → 一键改写**：英式 / 美式拼写、两类自定义要求、「测试连接」（用当前服务改写一句固定的中文，不碰剪贴板）。
- 使用上面选择的翻译服务。用 `claude -p` 时每次要启动一次命令，改写一段话通常 10–25 秒；直接调 API 一般一两秒。
- 需要「辅助功能」权限；需要目标输入框支持全选、复制和粘贴。任意第三方应用的输入框实现无法保证 100% 兼容。

## 翻译服务

在「设置 → 翻译服务」中切换：

| 服务 | 需要什么 | 说明 |
|---|---|---|
| Claude API | Claude API Key、模型名 | API 地址可改。 |
| AWS Bedrock（Claude） | Amazon Bedrock API Key、模型名 | 通过 Bedrock 使用 Claude，填区域和带 `anthropic.` 前缀的模型名。短期 Key 最长 12 小时有效。 |
| Bedrock 网关（Claude） | 网关地址、模型 ID、API Key | 企业网关或代理：请求 `地址/model/{模型ID}/invoke`，认证用 `x-api-key` 或 Bearer，可加额外请求头（如 `Send-Raw-Response-Header: true`）。不做 AWS SigV4 签名，不读取本机 AWS 凭据。 |
| OpenAI API | OpenAI API Key、模型名 | 使用 Chat Completions 接口。 |
| DeepSeek | DeepSeek API Key、模型名 | 不能看图。 |
| 通义千问 | 阿里云百炼 API Key、模型名 | OpenAI 兼容接口。 |
| 自定义（OpenAI 兼容） | API 地址和模型名 | Kimi、智谱、硅基流动、OpenRouter 等同格式的服务；本机的 Ollama 填 `http://localhost:11434/v1`，API Key 留空。 |
| claude -p | 已安装并登录的 [Claude Code](https://claude.com/claude-code)、模型名（如 `sonnet`） | 不需要 API Key，使用你的 Claude 账号额度。每次翻译要启动一次命令，比直接调 API 慢 1–2 秒。 |

每个服务的 API Key、地址和模型分开保存，切换服务不用重填。API Key 以明文保存在本机 `~/Library/Application Support/Fanyi/` 下的密钥文件里（文件权限 600，仅本人可读写；不加密，不写入安装包或源码），翻译和一键改写共用。旧版本存在钥匙串里的 Key 会在首次启动时自动搬过来并从钥匙串删除；搬不过来时设置里会提示重新填写。自定义服务和 Bedrock 网关可以填额外请求头。所有请求都不跟随 HTTP 重定向。

## 系统要求

- macOS 14 Sonoma 或更新
- 从源码编译需要：Xcode（开发时使用 Xcode 26.3）和 [XcodeGen](https://github.com/yonaskolb/XcodeGen)

## 下载安装

用 Homebrew 一行安装：

```bash
brew install --cask tianyaphoto/tap/fanyi
```

或者到 [Releases](https://github.com/tianyaphoto/fanyi/releases/latest) 下载 `Fanyi.zip`，解压后把 `Fanyi.app` 拖进「应用程序」文件夹。支持 Apple 芯片和 Intel 芯片的 Mac。

App 使用 Developer ID 签名并通过了苹果公证，双击即可打开。

项目主页：<https://tianyaphoto.github.io/fanyi/>

## 自动更新

从 1.2 开始内置自动更新（[Sparkle](https://sparkle-project.org/)）：每天检查一次，有新版本时弹窗显示更新说明，点「安装」后自动下载、校验签名、替换并重启。菜单「检查更新…」可以手动检查，设置 →「更新」可以关闭自动检查。设置、生词本、历史、资料库和 API Key 都会保留。1.1 及更早的版本需要手动下载一次 1.2。

## 从源码编译

发布新版本：在 `project.yml` 里把 `MARKETING_VERSION` 和 `CURRENT_PROJECT_VERSION` 加一，写好更新说明（`release-notes/版本号.html`），运行 `TEAM_ID=<你的 Team ID> RELEASE_NOTES=release-notes/版本号.html ./release.sh`：归档、Developer ID 签名、提交公证、钉上公证票据，输出 `dist/Fanyi.zip`，并用 Sparkle 私钥签名、更新 `docs/appcast.xml`。然后提交并推送 `docs/appcast.xml`，建 GitHub Release `v版本号`、上传 `dist/Fanyi.zip`（文件名保持 `Fanyi.zip`）。最后更新 Homebrew 安装源：`tools/bump-cask.sh`（把 [tianyaphoto/homebrew-tap](https://github.com/tianyaphoto/homebrew-tap) 里的版本号和 sha256 改成刚发布的包）。需要 Developer ID Application 证书、App Store Connect API 密钥和钥匙串里的 Sparkle 私钥，见脚本开头的说明。自己用的话按下面编译即可。

```bash
brew install xcodegen
git clone https://github.com/tianyaphoto/fanyi.git
cd fanyi
./build.sh install
```

`./build.sh install` 会生成 Xcode 工程、编译，把 App 安装到 `/Applications/Fanyi.app` 并启动。只想编译不安装的话，运行 `./build.sh`。

启动后菜单栏会出现一个写着「译」的气泡图标，第一次运行会自动打开设置窗口。

## 首次使用

1. **配置翻译服务**：在设置中选择服务，填入模型名（不预设模型，填服务商提供的模型名）；使用 API 的话，再填对应的 API Key。
2. **授予「辅助功能」权限**（划词翻译需要）：系统设置 → 隐私与安全性 → 辅助功能 → 允许「Fanyi」。
3. **授予「屏幕录制」权限**（截图翻译需要）：系统设置 → 隐私与安全性 → 录屏与系统录音 → 允许「Fanyi」，然后重新打开 App。

设置窗口的「权限」一栏会显示当前授权状态，并提供跳转按钮。

> 如果你的电脑上没有代码签名证书，App 会使用临时签名，每次重新编译后可能需要重新授予上面两项权限。`build.sh` 检测到本机有签名证书时会自动使用。

## 小贴士

- **读取不到选中文字**：Chrome、VS Code 等应用默认不提供文字内容。设置里的「增强取词」会让它们开启辅助功能支持，之后就能直接读取；仍然读不到时，「兼容模式」会触发一次应用的「拷贝」菜单项（没有时模拟 `⌘C`）来取词，并自动恢复剪贴板原内容。
- **系统词典结果**：显示哪本词典的内容取决于「词典」App 里启用的词典。想看英汉释义，请在「词典 → 设置」中勾选「牛津英汉汉英词典」。
- **原句读取范围**：备忘录、文本编辑、Pages、预览等原生应用读取效果最好，Safari 网页通常也可以；Chrome、VS Code 等应用需要打开「增强取词」才可能读到。走「兼容模式」拷贝取词时读不到原句，可以在生词本里手动添加。
- **增强取词的副作用**：被打开辅助功能支持的应用可能略微变慢；如果窗口管理工具的动画变得异常，在设置里关闭这一项并重启对应的应用。
- **Google 文档取词**：需要打开设置里的「兼容模式」（默认打开）。读不到原句，所以没有「结合语境」的释义。想把 Google 文档加进资料库，先「文件 → 下载」成 Word 或纯文本，或者复制全文后在资料库里「粘贴文字」。
- **资料库检索**：用关键词检索（BM25），在本机完成，不额外调用任何服务。能找到用词相同的资料；中英文之间的对应请写进术语表。
- **只翻译，不回答**：要翻译的内容即使是问题或指令（例如「What is the capital of China?」），也只会译成「中国的首都是哪里？」，不会回答成「北京」。App 会在本机先判断单词还是句子、译成什么语言，翻完再检查输出像不像译文（语言、问句、长度），不像就自动重翻一次；两次都不过关时浮窗会提示“可能不准确”。
- **换了签名后权限失效**：从下载版换成自己编译的版本（或反过来）时，如果签名证书不同，macOS 会把它当成另一个 App，需要在「隐私与安全性」里重新允许辅助功能和屏幕录制。
- **截图识别效果**：OCR 支持中英文和设置里选的两种语言。识别出的文字如果有错字或多余断行，模型会先修正再翻译。
- **看图翻译**：设置 → 截图翻译 里打开。默认关闭，此时截图只在本机识别，发给模型的只有文字；打开后截图会上传给所选的翻译服务。使用自定义服务时所选模型需要支持图片输入；DeepSeek 和通义千问不看图，仍按本机识别处理。

## 数据存储

所有数据都只保存在本机：

| 内容 | 位置 |
|---|---|
| 生词本 | `~/Library/Application Support/Fanyi/vocabulary.json` |
| 查词历史（最多 2000 条，可在设置中关闭） | `~/Library/Application Support/Fanyi/history.json` |
| 资料库和术语表 | `~/Library/Application Support/Fanyi/knowledge.json` |
| 翻译场景 | App 的偏好设置（`com.local.fanyi`） |
| API Key | `~/Library/Application Support/Fanyi/` 下的密钥文件（明文，权限 600） |

要翻译的文字、划词时读取到的所在原句，以及从资料库检索出的相关片段和命中的术语，会发送给你选择的翻译服务。

## 项目结构

```
Sources/
├── App.swift              # 入口、菜单栏菜单、窗口管理
├── Coordinator.swift      # 串联划词、截图、输入翻译；小图标和翻译浮窗
├── Selection.swift        # 读取选中文字、监听划词手势
├── Context.swift          # 读取原句和来源文档
├── Translator.swift       # 各翻译服务的流式调用、提示词拼装
├── Scenes.swift           # 翻译场景与自动识别
├── Knowledge.swift        # 资料库：导入、切段、BM25 检索、术语表
├── LibraryView.swift      # 「场景与资料库」窗口
├── Quality.swift          # 翻译方式判断、译文检查与自动重翻
├── Polish.swift           # 一键改写：全选/复制/改写/粘贴/回读确认、链接代码保护
├── Diagnostics.swift      # 一键改写的诊断日志、不抢焦点的短提示
├── Eval.swift             # 开发用：翻译评测（FANYI_EVAL=tests/translation-cases.json）
├── Debug.swift            # 开发用：演示数据截图（FANYI_DEMO_DIR）
├── LocalDictionary.swift  # macOS 系统词典查询
├── TranslationView.swift  # 翻译浮窗界面
├── Vocabulary.swift       # 生词本
├── History.swift          # 查词历史
├── Shortcuts.swift        # 快捷键配置与录制
├── HotKeys.swift          # 全局快捷键注册（Carbon）
├── Settings.swift         # 设置项
├── APIKeyStore.swift      # API Key 的本机明文文件存储（含从旧钥匙串一次性迁移）
└── SettingsView.swift     # 设置界面
Resources/Assets.xcassets  # App 图标、菜单栏图标（由 tools/make-icons.sh 从 design/*.svg 生成）
project.yml                # XcodeGen 工程描述
build.sh                   # 编译与安装脚本
```

`Fanyi.xcodeproj` 和 `Info.plist` 都由 XcodeGen 根据 `project.yml` 生成，不纳入版本管理。想在 Xcode 里开发的话，先运行 `xcodegen generate`，再打开 `Fanyi.xcodeproj`。
