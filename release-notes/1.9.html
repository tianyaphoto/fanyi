翻译神器 1.9

  • 改写后看得见改了哪里，还能撤回、换语气：一键改写替换完成后，输入框旁边出现一个小浮窗，删掉的字标红、加上的字标绿。点「撤回」恢复原文；点「更正式 / 更简短 / 更口语」，或者再按一次改写快捷键，换一种语气重新改写。不想要可以在设置 → 一键改写里关掉。
  • 生词本导出到 Anki：生词本底部「导出」→「发到 Anki」，卡片正面是原句和生词，背面是释义和「帮你记住」。需要 Anki 开着并装了 AnkiConnect 插件（代码 2055492159）；没装也可以导出成文件再导入。
  • 今日复习与统计：菜单「今日复习」每天抽 5 个到期的生词，先看原句回想，再翻开看释义。同一个窗口里能看到最近 7 天查了多少词、反复查的是哪些词。
  • 截图识别文字（只复制）：按 ⌥⇧S 框选，识别出的文字直接进剪贴板，不翻译、不弹窗。
  • 不配 API Key 也能翻译：翻译服务里新增「系统翻译」（macOS 15 起），在本机完成，新安装时默认用它。它只会翻译；语境释义、帮你记住、一键改写仍然需要大模型服务。已经配好服务的不受影响。
  • 匿名统计使用台数：每天检查更新时，App 会带上自己的版本号，更新服务器据此统计“今天有多少台机器在用”。不保存 IP 地址，不含任何翻译内容；在设置里关掉自动检查更新就不会发送。统计服务不通时会自动改用原来的地址，不影响更新。
