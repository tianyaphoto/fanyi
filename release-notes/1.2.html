翻译神器 1.2

  • 一键改写：在聊天框或文档里按 ⌃⌥⌘T，中文自动译成英文、英文自动纠错润色，直接替换原文；也可以按 ⌃⇧⌘C 改写剪贴板内容。
  • 只翻译，不回答：要翻译的内容即使是问题或指令，也只会被翻译；翻完自动检查，不像译文会重翻一次。
  • 自动更新：以后有新版本会提示你，一键安装。
  • 新图标：App 图标和菜单栏图标换新。
  • Bedrock 网关：可以通过企业网关调用 Bedrock 上的 Claude，支持自定义请求头。
  • 修复：点浮窗上的朗读、固定按钮时浮窗被关掉；模拟按键后系统误以为 ⌘ 一直按着；浮窗左上角多出窗口按钮。
  • API Key 改为保存在本机的明文文件里（仅本人可读写），翻译和改写共用。
