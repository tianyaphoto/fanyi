Understand it.

Fanyi is a lightweight macOS menu bar translator for English ⇄ Chinese. Select text in any app, translate screenshots, and turn what you are typing into natural English with one shortcut — with translation rules that change with where you are: documents, code, chat or contracts.

Download for macOS View source
Free and open source (MIT) · Notarised by Apple · macOS 14+ · Apple silicon and Intel · The app's interface is in Chinese · All releases

Features

Lives in the menu bar and stays out of your way. Words get pronunciation, senses and examples; sentences and paragraphs get a fluent translation; Chinese ⇄ English by default, or any two of 16 languages.

Select to translate

Select text in any app, click the little icon next to the pointer, or press ⌥D. Works in Chrome, VS Code and Google Docs too.

Screenshot translation

Press ⌥S and drag a box; text is recognised on your Mac and translated. Optional vision mode for tables, formulas and handwriting.

Input translation

Press ⌥A, type, press Return — like Spotlight for translation.

Translates, never answers

A question or instruction is translated, not answered. Output is checked and retried once if it doesn't look like a translation.

Words in context

Looking up a word reads the sentence it came from and explains what it means right there, after the instant dictionary entry.

Any two languages

Chinese ⇄ English by default; pick any two of 16 languages instead — Vietnamese ⇄ English, English ⇄ Korean, Japanese ⇄ Chinese. Override the target per translation from the popup.

One-key polish

Press ⌃⌥⌘T in any text field: Chinese becomes English, English gets fixed — pasted back in place.

Vocabulary book

Save words with the sentence and document they came from; repeated lookups are flagged so you notice what to learn.

Auto-update

New versions show their release notes and install in one click. Your settings and data are kept.

One-key polish

Write your message in the chat box or document, press ⌃⌥⌘T: Chinese or mixed text becomes concise, natural work English; English gets its spelling and grammar fixed. The result replaces your text — Fanyi never presses Return for you.

  • Clipboard too: copy some text and press ⌃⇧⌘C to paste the rewrite at the cursor.
  • Rewrites, never answers: questions stay questions, requests stay requests.
  • Keeps what matters: links and code stay verbatim; British spelling by default (American optional); add your own instructions.
  • Pastes in the right place: it checks you are still in the same field and didn't type or click meanwhile, then reads the field back to confirm.
  • Diagnostics log: every step is recorded, never your text.

Translation scenes

The same English deserves a different translation in a design doc, a code review, a Slack thread or a contract. Fanyi picks the scene from the current app, window title and URL; switch it from the popup, tell it to remember a site, edit each scene's rules or create your own.

DocumentFormal written style, headings, lists and tables kept, consistent terms. Google Docs, Notion, Word, Feishu…
TechnicalCode, commands and error messages untouched, standard industry terms. GitHub, VS Code, Terminal, docs sites…
AcademicRigorous academic style; citations and formulas kept; terms glossed on first use. arXiv, Google Scholar…
Email & chatFollows the tone of the original; English replies read like a native speaker wrote them. Slack, Mail, WeChat, Teams…
ContractsStrictly literal, distinguishes shall / may, defined terms consistent throughout.
General / customEverything else uses the general rules — or create your own scene, e.g. “insurance product docs”.

Knowledge base & glossary

Add your project docs, product notes or past translations. Fanyi retrieves the most relevant passages on your Mac and uses them as reference, so names and phrasing match your own material.

  • Formats: text, Markdown, PDF, Word, RTF, HTML — drag in files or whole folders.
  • Glossary: one “source = target” per line, always applied; import CSV.
  • Per scene: limit a document to certain scenes.
  • Visible: the popup shows “References N” — click to see what was used.
  • Local search: retrieval runs on your Mac; no extra service is called.

Install

With Homebrew: brew install --cask tianyaphoto/tap/fanyi — or download, unzip, drag into Applications, double-click.

Download and unzip

Download Fanyi.zip, unzip it and drag Fanyi.app into Applications.

Open

It is notarised by Apple, so it opens with a double-click. Look for the speech-bubble icon in the menu bar.

Pick a service

Settings open on first launch. Choose a translation service and paste its API key and a model name (none is preset) — or use claude -p with Claude Code, no key needed.

Grant permissions

Accessibility for select-to-translate and one-key polish; Screen Recording for screenshot translation. The settings window links to both.

Build it yourself: brew install xcodegen, clone the repo, run ./build.sh install.

Privacy

Your vocabulary, history, knowledge base and API keys stay on your Mac (keys in a plaintext file readable only by your account). The text you translate or polish, the surrounding sentence and any retrieved reference passages are sent to the service you chose — nowhere else. Polish keeps your original and the result in memory only.
